MTF / CDR Toolkit - User Manual

Comprehensive step-by-step operating guide for all 6 converters
100% Client-Side Secure
Quick Start & Architecture Overview:
1. Open the portal in your browser and sign in (Username: Admin, enter your password).
2. Select your desired tool from the left navigation sidebar.
3. Privacy Guarantee: All files are processed directly inside your browser memory (RAM); your data is never uploaded to any remote server.
1
Disposition Remark Converter
CSV Filter + Remark Merger + Excel Export
Business Purpose: Filter raw dialer CDR CSV for MTF-CROSS SELL campaign, attach manual remarks (e.g. Dropped During Conversation) to Interested leads, and generate segmented Excel reports.
Step-by-Step Instructions:
  1. Step 1: Click Upload the CDR CSV file to select your raw dialer file. The tool automatically isolates MTF-CROSS SELL campaign records.
  2. Step 2: Paste your remarks and Record IDs in the text box.
    Supported Format Example:
    Dropped During Conversation
    lead_id: 211296
    lead_id: 211666
  3. Step 3: Select the date and choose your download format:
    • Interested only: Excel file containing only 'Interested' remarks.
    • Connected to executive only: Excel file containing 'Connected to executive' remarks.
    • Download both files: Full updated spreadsheet.
Verification Tip: Check the live counter below Step 2: "Remarks found: X, without remark: Y". Any invalid or extra IDs are highlighted.
2
Excel to JSON Converter
Spreadsheet to CRM API JSON Converter
Business Purpose: Convert calling records (.xlsx, .xlsm, or .csv) into clean, standardized CRM API JSON arrays for bulk API updates.
Step-by-Step Instructions:
  1. Step 1: Drag and drop your Excel or CSV file into the designated upload zone.
  2. Step 2 (Column Mapping): The tool automatically maps lead_id, call_id, disposition, and sub_disposition. Adjust dropdowns if needed.
  3. Step 3: Formatted JSON renders instantly on the right. Click Copy JSON or Download .json.
Auto-Cleaning: Duplicate Call IDs are automatically discarded, and rows with missing IDs are safely dropped.
3
API Request Sender
Integrated API Dispatcher & Testing Tool
Business Purpose: Directly send the JSON generated in Tool #2 to your target CRM or dialer API without needing external tools like Postman.
Step-by-Step Instructions:
  1. Method & Endpoint: Select HTTP Method (e.g. POST) and enter your API URL (e.g., https://crm.company.com/api/v1/update).
  2. Authentication: Select your auth scheme from the dropdown (Bearer Token / Basic Auth / API Key header).
  3. Load Payload: Click Use JSON from converter — the JSON payload from Tool #2 is automatically loaded into the body.
  4. Dispatch: Click Send. The live HTTP response code (200 OK), round-trip latency (ms), and body will appear below.
Security Protection: All calls route through an authenticated Vercel serverless proxy with SSRF protection blocking private IP access.
4
Download Answer Null CDR
Telephony Gateway Answer + CRM Null Filter
Business Purpose: Extract calls that successfully connected at the gateway telephony level but remained un-dispositioned (Null) in CRM.
Step-by-Step Instructions:
  1. File Upload: Drop your raw CDR CSV file into the upload zone.
  2. Verify Filters:
    • Campaign Name: MTF-CROSS SELL (default)
    • Gateway Disposition: ANSWER (default)
    • CRM Disposition: Keep null rows only (default)
  3. Convert: Click Convert & Download XLSX. A clean, filtered spreadsheet downloads instantly.
Verification Tip: Check the stage flow badges: Total Rows → Campaign Matches → Gateway Answered → Final Null Count.
5
Answer Null Lead Data
Standard 57-Column CRM Import Formatter
Business Purpose: Convert filtered Answer Null records into the standard 57-column CRM import spreadsheet template for re-allocation.
Step-by-Step Instructions:
  1. Upload Lead Data: Drop your Lead Data spreadsheet (.xlsx) into the file card.
  2. Timestamp Batch: Use the date_entered picker to specify the date and time for the batch.
  3. Convert & Download: Click Convert & Download. The formatted file [Date]_MTF_ANSWER_NULL.xlsx will download.
Required Columns: The file must contain: CUSTOMER NAME, RECORD ID, Remark, CALL ID, and CALL ATTEMPT.
6
Sub-Disposition Pivot Converter
Pivot Reporting & High-Res PNG Screenshot Generator
Business Purpose: Instantly analyze Sub-Disposition frequency breakdowns, calculate Call Connectivity %, and export graphical report cards for WhatsApp/Email.
Step-by-Step Instructions:
  1. Upload File: Drop your CDR CSV or Excel file into the upload zone.
  2. Instant Analysis: Two live tables render immediately:
    • Table 1: Sub-Disposition Pivot (Dispositions count breakdown + Grand Total).
    • Table 2: Call Summary (Dialed Calls, Connected Calls, Answer Null Calls, Connectivity %).
  3. Export Options:
    • Copy screenshot: Copies a crisp 2x retina PNG to your clipboard for instant Ctrl + V into WhatsApp or Email.
    • Download screenshot (PNG): Saves the graphical image to your drive.
    • Download Excel (.xlsx) or Download CSV.
Formula: Connectivity % = (Connected Calls / Total Dialed Calls) × 100.
Standard Troubleshooting & Checklist
Issue Probable Cause Resolution
"Columns not found" error Spreadsheet header names differ from standard names Verify standard header names (e.g., CAMPAIGN NAME, CRM SUB-DISPOSITION, RECORD ID).
"No rows matched" Campaign name spelling or case mismatch Ensure the campaign name matches MTF-CROSS SELL exactly.
Screenshot copy failed Browser clipboard write permissions denied Use the "Download screenshot (PNG)" button instead.
